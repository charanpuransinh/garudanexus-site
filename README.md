# garudanexus-site

**माँ आदिशक्ति ग्रुप · GARUDA NEXTECH** की आधिकारिक स्थिर (static) वेबसाइट: **garudanexus.com**

सिर्फ़ HTML + CSS + साधारण JavaScript। कोई framework, build tool, npm या बाहरी CDN नहीं। फ़ोन पर तेज़ खुलती है और सीधे सर्वर पर कॉपी होती है।

---

## 1. पूरी प्रक्रिया एक नज़र में

| क्रम | पेज | काम |
|---|---|---|
| 1 | **होम** (`index.html`) | लोगो, टैगलाइन, ग्रुप का परिचय, "Products देखें" बटन, संपर्क |
| 2 | **Products** (`products.html`) | हर product का एक card: आइकन, नाम, एक लाइन, स्थिति, बटन |

आगे कोई भी पेज बनाना हो तो इसी क्रम और इसी डिज़ाइन से बनाएँ: **पहले होम, फिर Products, फिर हर product का पेज।**

## 2. डिज़ाइन नियम (हर पेज पर एक जैसे)

### रंग (सिर्फ़ यही)

| काम | रंग |
|---|---|
| बैकग्राउंड | `#0a1a3a` गहरा नीला |
| card / panel | `#10264f` |
| लाइन, बॉर्डर, मुख्य बटन, शीर्षक | `#d4af37` सुनहरा |
| टेक्स्ट | `#ffffff` सफ़ेद |

सुनहरा रंग कम और सोच-समझकर लगाएँ: लाइनें, बॉर्डर, एक मुख्य बटन, शीर्षक। जहाँ हर चीज़ सुनहरी हो वहाँ कुछ भी अलग नहीं दिखता।

### लोगो और नाम
हर पेज के ऊपर **बीच में लोगो**, उसके नीचे "माँ आदिशक्ति ग्रुप" और "GARUDA NEXTECH"। उसके नीचे सुनहरी लाइन और menu (होम / Products)।

### अक्षर (fonts)
- सिर्फ़ system fonts: कोई फ़ॉन्ट डाउनलोड नहीं होता, इसलिए पेज तुरंत खुलता है।
- शीर्षक: serif (Georgia / Noto Serif Devanagari), जो भरोसेमंद और पारंपरिक लगता है।
- सामान्य टेक्स्ट: system sans-serif, आकार कम से कम 17px।
- हर जगह हिंदी और अंग्रेज़ी साथ-साथ और साफ़।

### फ़ोन पहले (mobile-first)
- पहले छोटी स्क्रीन के लिए डिज़ाइन, फिर बड़ी के लिए: 1 कॉलम (फ़ोन) → 2 कॉलम (टैबलेट) → 3 कॉलम (कंप्यूटर)।
- हर बटन कम से कम 48px ऊँचा, ताकि अँगूठे से आराम से दबे।
- पेज के किनारे पर कभी बगल में खिसकना नहीं पड़े।

### सुगमता (accessibility)
- **स्थिति सिर्फ़ रंग से नहीं, शब्द में भी**: Live (चालू) / Soon (जल्द आ रहा) / Private (लॉगिन के बाद)।
- सफ़ेद टेक्स्ट और सुनहरे बॉर्डर नीले बैकग्राउंड पर साफ़ पढ़े जाते हैं।
- कीबोर्ड से चलाने पर सुनहरा घेरा दिखता है (focus)।
- आइकन सजावट के लिए हैं; अर्थ हमेशा शब्दों में लिखा रहता है।

## 3. हर पेज कैसा हो

### होम पेज
1. ऊपर: लोगो, नाम, menu
2. बड़ा शीर्षक + एक लाइन का टैगलाइन
3. एक ही बड़ा सुनहरा बटन: **Products देखें**
4. "ग्रुप के बारे में": 2-3 लाइन हिंदी में, 2 लाइन अंग्रेज़ी में
5. "संपर्क": असली ईमेल और फ़ोन
6. नीचे: footer

इससे ज़्यादा कुछ नहीं। होम पेज का काम एक है: आने वाले को Products तक पहुँचाना।

### Products पेज
- हर product का एक card (आइकन, नाम, हिंदी नाम, एक लाइन, स्थिति, बटन)
- कार्ड `products.json` से अपने-आप बनते हैं, `order` के क्रम में
- हर card पर दो बटन: **खोलें** (live/private के लिए) और **विवरण** (उस product का अपना पेज)
- "soon" वाले card का "खोलें" बटन बंद रहता है
- `products.json` न मिले तो साफ़ संदेश और "फिर कोशिश करें" बटन दिखता है, खाली पेज नहीं

### Product पेज
बीच में: आइकन → नाम → हिंदी नाम → स्थिति → विवरण (हिंदी + अंग्रेज़ी) → (वैकल्पिक) खूबियों की सूची → "खोलें" और "सभी Products" बटन।

### Login (ध्यान दें)
यह **स्थिर साइट है, इसलिए असली लॉगिन इसमें नहीं बन सकता।** लॉगिन हर product के अपने सर्वर पर रहे (जैसे GTS Tools का PIN लॉगिन)। साइट पर "Private" product का बटन सीधे उसी लॉगिन पेज तक ले जाए।
HTML या JavaScript में PIN या पासवर्ड कभी न जाँचें: उसे कोई भी पढ़ सकता है।

## 5. नया product जोड़ना (सिर्फ़ `products.json`)

HTML या JS बदलने की ज़रूरत नहीं। सूची में एक object जोड़ें:

```json
{
  "id": "yarn",
  "name": "Textile Yarn",
  "name_hi": "टेक्सटाइल यार्न",
  "tagline": "कपड़ा उद्योग के लिए यार्न",
  "icon": "🧵",
  "url": "https://yarn.garudanexus.com",
  "status": "live",
  "order": 1,
  "description_hi": "विवरण हिंदी में",
  "description": "Description in English",
  "features": ["खूबी 1", "खूबी 2"]
}
```

- `id`: छोटा, अंग्रेज़ी, बिना खाली जगह के, और हर product का अलग।
- `status`: `live` (चालू), `soon` (जल्द, बटन बंद), `private` (लॉगिन के बाद)।
- `url`: पता `https://` से शुरू हो। "soon" में खाली रख सकते हैं।
- `description_hi`, `description`, `features`: वैकल्पिक।
- `order`: जिस क्रम में दिखाना है।
- **`products.json` सार्वजनिक है:** इसमें कोई निजी पता, पासवर्ड या API key न डालें।

## 6. सर्वर पर चलाना (Ubuntu + nginx)

### पहली बार
```bash
cd /var/www && git clone https://github.com/<आपका-username>/garudanexus-site.git
```

### nginx
इस साइट के लिए **अलग `server` ब्लॉक** रखें। पहले से चल रहे ब्लॉक (जैसे testlab, GTS) न छुएँ।

```nginx
server {
    listen 80;
    server_name garudanexus.com www.garudanexus.com;
    root /var/www/garudanexus-site;
    index index.html;
    error_page 404 /404.html;
    location / { try_files $uri $uri/ =404; }
    location = /products.json { add_header Cache-Control "no-cache"; }
}
```

फिर जाँचकर लागू करें और https चालू करें:
```bash
nginx -t && systemctl reload nginx
certbot --nginx -d garudanexus.com -d www.garudanexus.com
```
**पहले देख लें कि garudanexus.com अभी किस nginx ब्लॉक से चल रहा है**, ताकि पुराना काम न टूटे।

### बदलाव के बाद अपडेट
GitHub पर बदलाव करें (या `products.json` एडिट करें), फिर सर्वर पर:
```bash
cd /var/www/garudanexus-site && git pull
```
